# Formato Excel de prueba
La primera hoja del archivo .xlsx debe contener encabezados en la fila 1:
A: Código, B: Descripción, C: Unidad, D: Metrado, E: Precio unitario.
Desde la fila 2 se leen partidas con metrado y precio numéricos.
Esta es una importación inicial, no una integración verificada con el formato nativo de S10.
La exportación actual es CSV de partidas, NO un cronograma de Microsoft Project.
No se calculan duraciones ni precedencias todavía.
